FAQ

Common questions before getting started.

Which package should I choose?

Choose Starter if you need a clean first page, Growth if you need better copy and lead capture, and Launch if you need the full offer and systems structure.

Can this site be hosted on GitHub and Cloudflare?

Yes. This package is static HTML, CSS, JavaScript, and images, so it can be deployed with Cloudflare Pages from a GitHub repository or with GitHub Pages plus Cloudflare DNS.

Do I need a backend for the contact form?

No backend is required for this version. The form opens a prefilled email. You can later connect Formspree, Cloudflare Workers, HubSpot, or another CRM.

Can we add payments or booking?

Yes. The next step would be adding Stripe payment links, Calendly, Square, or another booking/payment system based on how you want clients to buy.
